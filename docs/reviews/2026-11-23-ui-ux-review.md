# UI/UX review — 2026-11-23

Independent review of `main` at **v7.54.2** (commit `7664a74`) by the UI/UX role of the review team
([README](README.md)). Read only: no code, test, setting or other document was changed.

## 1. Scope and method

- **Role:** UI/UX only (`review-uiux`). The Developer, Tester, Peer, Code and Design Defaults roles were not run for this
  review, so logic, test, code-quality and defaults findings are out of scope except where they show in the UI.
- **Slices:** four, one reviewer run each.

| Slice | Content | Files read in full |
|---|---|---|
| S1 | App shell, navigation and styles (`App.tsx`, `main.tsx`, `App.css`, `fresh.css`, `index.css`, shared components, Home, Docs, registry) | 40 |
| S2 | Dashboards and insights (Team overview, My dashboard, Pulse Check, Monthly pack, KPI tracker, Baselines, Planning Overview, Capacity vs Actual, PI Review) | 16 |
| S3 | Work items and Azure writes (QMS-0025 tree, editors, bulk create, Close dialog, My Tasks, Sprint check, Time Writing, Backlog health, releases) | 28 |
| S4 | Admin, settings and data (Admin page, connections, Git storage, access, settings panels, QE Mapping, Snapshots, BRITE, Windchill views) | 22 |

  All 106 files of the four slices were read in full. Reviewers also read parts of files outside their slice only to
  prove a finding (for example `ui.tsx`, `access.ts`, `azureClient.ts`, `useGitStorage.ts`, `store.ts`, `adminOverview.ts`).
- **Runtime checks done:** the existing `dist` build with `e2e/helpers.mjs` and the synthetic sample; light and dark
  themes; 1440, 900 and 390 px widths; keyboard walks with Playwright focus tracking; DOM probes (ARIA wiring, tab order,
  focus after close); a simulated page-chunk failure; contrast measured for some elements (UX-09, UX-20, UX-44, UX-54).
- **Runtime checks not done:** no live Git, SharePoint or Azure DevOps (the sample disables them; no token or PAT was
  entered); no Role rights editing with restricted roles; no real Electron desktop paths (zoom was mocked); no axe run
  and no screen reader (NVDA / VoiceOver) — role and name findings come from the markup; no 200 % zoom; contrast only
  partly measured, the rest judged by eye.
- **Merge:** every `path:line` below was opened at HEAD and the quoted code confirmed. Duplicates across slices were
  merged; the **Sources** column keeps every slice finding ID (and its original severity where it differed). Final IDs
  are ranked by severity, then by how many users a finding reaches.

**Top 10 to act on first**

1. **UX-01** — Pop-ups have no keyboard model (no first focus, no Escape, Tab escapes, focus lost on close); every dialog.
2. **UX-02** — Dark mode: Backlogs and Sprint check tables are white with near-white text.
3. **UX-03** — Git "Load latest" buttons overwrite unsaved shared changes without warning, also on a conflict.
4. **UX-04** — A click beside any Azure write pop-up closes it and discards what was typed.
5. **UX-05** — In sample mode / without a PAT the QMS-0025 tree keeps writes enabled; Time Writing Tasks closes, loses hours and gives the wrong reason.
6. **UX-06** — Write controls are shown to roles without the right and fail only after the user fills the form (CR-P1-03 still open).
7. **UX-07** — Edit form: the PAT field vanishes after one character and the form waits for ever.
8. **UX-08** — Texts send people to settings places that do not exist (work email, Bulk creation Epics, Release counts); KB-53 is not fixed.
9. **UX-09** — Keyboard focus ring is nearly invisible (about 1.4:1).
10. **UX-10** — Phones: the hidden side menu stays in the Tab order (about 40 stops before the page).

Common causes worth one fix each: the shared `Modal` (UX-01, UX-04), one shared Tabs component (UX-17, UX-18), one
place for settings directions (UX-08, UX-83, UX-97), dark-mode tokens instead of fixed colours (UX-02, UX-20, UX-21,
UX-44, UX-52), and one "unsaved draft" guard (UX-14, UX-15).
