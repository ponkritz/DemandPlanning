### 1.3 Top 10 to act on first

These are the ten bugs of §4 "Fix first", to fix before any clean-up: AR-001, AR-002, AR-003, AR-004,
AR-005, AR-006, AR-007, AR-008, AR-010, AR-011. Two of them are Critical. AR-001 lets the Admin role rewrite the shared stream mapping
around the CON-93 rule. AR-002 lets one admin's save of access.json silently overwrite another admin's newer change.
The other eight are High: Tool Owner checks that can be bypassed, a PAT sent to the wrong server, a regex that can
freeze the browser tab, a shared file that stops loading above 1 MB, a bulk dialog that clears data by default, and
access that cannot be removed.
